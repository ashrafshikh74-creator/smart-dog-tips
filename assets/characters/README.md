# PawTint World — Mascot Asset Library

## Character canon
- **بودى / Bodi:** golden puppy explorer; blue explorer cap and scarf, field backpack, compass; adventurous and encouraging.
- **لولى / Loli:** ivory/lilac puzzle cat; pink bow, purple outfit, puzzle pendant; clever, playful and observant.
- **بيردى / Birdy:** turquoise/yellow guide bird; aviator goggles, green scarf and satchel; gives hints and connects activities.

## Files
- `bodi.svg` — lightweight original vector fallback used in the homepage cast and personalized pet-home.
- `loli.svg` — lightweight original vector fallback used in the homepage cast and personalized pet-home.
- `birdy.svg` — lightweight original vector used in the homepage cast and game-room guide strip.

## Use
All SVGs use a 420×420 viewBox and transparent vector canvas. Keep image alt text descriptive, preserve intrinsic aspect ratio with `object-fit: contain`, and avoid using the mascots as text replacements. UI labels and dialogue remain live HTML.

## Production status
The SVGs are functional lightweight web illustrations, not substitutes for the high-detail concept renders. High-detail PNG masters and expression/pose variants remain separate deliverables. Validate each asset at mobile and desktop scale before treating it as release-ready.
